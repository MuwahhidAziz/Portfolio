Model has one input layer, one convolution layer, one poolinglayer, one flattening layer, one dense layer, then a dropout layer and then annother dense layer as output. The dropout rate is initially `0.5` and units in the first dense layer are `128`. The output layer uses `softmax` activation while others use `relu` activation. All works well but the accuray is at `37.73%`. Adding another convolution and a pooling layer improved it significantly to `91.39%`. However when one more convolution and pooling layers were added it only improved training accuracy but no significant effect on test accuracy (about `0.5%`). But adding these layers one more time resulted in an error. This time the dropout was set to `0.3` and it boosted both training accuracy and test accuracy. The test acuracy was `93.24%`. Setting the dropout to `0.25` brought the test accuracy to `94.42%` while final training accuracy was `94.45%`, this was first time that test accuracy was lower than training accuracy. Droput of 0.1 decreased the accuracy to `89.94%` while training accuracy was near `95%`. After many experiments the droput of `0.21` had beeen observed as best giving an accurracy of `95.85%`.
